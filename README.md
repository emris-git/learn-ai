# ИИ — это просто

Бесплатные уроки, которые помогают людям 60+ освоить ИИ-помощников на практике. Уроки не привязаны к одной компании и учитывают российские ограничения: блокировки, VPN, недоверие к отдельным брендам.

## Что внутри

**Сайт** (`site/`) состоит из трёх частей:

- **Набор для помощника** (`pomoshchniku.html`): как детям и внукам научить родителей за 4 встречи. Подготовка телефона, правила занятий, частые трудности.
- **4 урока**:
  1. Первый разговор с ИИ: как задать вопрос, уточнить ответ, говорить голосом.
  2. ИИ понимает фотографии: квитанции, лекарства, растения, снимки экрана.
  3. Можно ли верить ИИ и как защититься от мошенников, которые подделывают голоса.
  4. ИИ в повседневных делах: письма, поздравления, анализы, книга воспоминаний.
- **4 шпаргалки**: каждая на одном листе A4 крупным шрифтом, для печати.

Плюс страница «Инструменты»: какой помощник выбрать, что работает без VPN, что понимает фото.

## Принципы

1. **Навык важнее инструмента.** Каждое задание работает в любом ИИ-помощнике.
2. **Минимум теории.** «Что такое ИИ» занимает одну минуту.
3. **Польза в первые 5 минут**: задания на бытовых задачах.
4. **Безопасность в каждом уроке.**
5. **Не больше двух инструментов**: основной и запасной.
6. **Без внешних зависимостей**: сайт не грузит шрифты и скрипты со сторонних серверов, поэтому быстро открывается в России.
7. **Доступность**: сайт проверен автоматическим аудитом axe-core (WCAG 2.1 AA) во всех цветовых схемах.

## Для людей с плохим зрением

- **Кнопка «Для слабовидящих»** в шапке каждой страницы, как на сайтах госуслуг (по мотивам ГОСТ Р 52872). Можно выбрать:
  - размер текста: А, А+ или А++;
  - цвета: обычные, чёрным по белому, белым по чёрному или синим по голубому;
  - обычное или увеличенное расстояние между буквами.

  Настройки запоминаются для всех страниц.
- **Прослушать страницу:**
  - голосом телефона: работает бесплатно и без внешних сервисов, читаемый абзац подсвечивается, есть медленный режим;
  - записью диктора (ElevenLabs): плеер появляется, если для страницы есть файл `src/audio/<страница>.mp3`.
- База доступности: крупный шрифт от 20px, кнопки не меньше 48px, ссылка «Перейти к содержанию», заметная рамка фокуса для управления с клавиатуры, таблицы с версией текста для чтения вслух (атрибут `data-say`).

## Озвучка диктором (ElevenLabs)

```
python3 tts.py --text                  # выгрузить тексты для озвучки в audio-text/ и посчитать символы
python3 tts.py --voices                # голоса в аккаунте
python3 tts.py                         # записать уроки 1–4 голосом Maxim в src/audio/
python3 build.py                       # плеер появится на страницах уроков
```

Ключ берётся из переменной `ELEVENLABS_API_KEY`. Озвучка всех 4 уроков — около 12,5 тыс. символов (≈16 минут аудио). Голос по умолчанию — Maxim (русский диктор), другой голос: `--voice <VOICE_ID>`. После правки текста урока перезапишите его: `python3 tts.py urok-2`. Произношение аббревиатур («ИИ» → «И-И» и т. п.) настраивается в `PRONOUNCE`: в `tts.py` и в `src/a11y.js`.

## Как редактировать

- Тексты страниц лежат в `src/*.html`, стили — в `src/style.css`, версия для слабовидящих и чтение вслух — в `src/a11y.js`.
- Сборка: `python3 build.py`. Скрипт добавит шапку и подвал и положит готовые страницы в `site/`.
- Посмотреть локально: откройте `site/index.html` в браузере.

## Публикация

Сайт публикуется через GitHub Pages (`.github/workflows/pages.yml`) при каждом пуше в `main`. Один раз нужно включить: **Settings → Pages → Source: GitHub Actions**.
