# learn-ai — ИИ для людей 60+

Проект помогает людям старшего возраста освоить ИИ-помощников на практике — без привязки к одной компании и с учётом российских ограничений (блокировки, VPN, недоверие к отдельным брендам).

## Проблема

- Ресурсы раздроблены: часть сервисов недоступна из РФ, часть требует VPN и иностранный номер, часть (Яндекс, Сбер) кому-то не нравится.
- Курсы учат **инструмент**, а не **навык**. Инструмент меняется или блокируется, и человеку приходится начинать заново.
- Люди 60+ — главная цель мошенников, которые используют ИИ (подделку голоса, фейковые видео). Это не теоретический риск, а повод начать учиться прямо сейчас.

## Принципы

1. **Навык важнее инструмента.** Каждый урок даёт навык, который переносится в любой сервис. К нему прилагаются 2–3 инструмента на выбор: без VPN и с VPN.
2. **Минимум теории.** «Что такое ИИ» — 5 минут, дальше сразу практика.
3. **Польза в первые 5 минут.** Первое задание решает настоящую бытовую задачу человека.
4. **Безопасность в каждом уроке**, а не в отдельной главе в конце.
5. **Не больше двух инструментов** у одного человека. Иначе путаница.
6. **Офлайн-поддержка:** распечатанные шпаргалки крупным шрифтом и короткие занятия по 15–20 минут.
